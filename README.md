# doubao-competitor-report（竞品分析报告生成 Skill）

面向专业评审/面试场景的竞品分析报告生成器：输入"公司/产品名称 + 赛道"，自动产出五段式、高干货、强证据、重对比的中文竞品分析报告，并交付为飞书在线文档。

## 目录结构

```
doubao-competitor-report/
├── SKILL.md                          # 技能入口：触发方式、执行流程、证据底线
└── references/
    ├── report-structure.md           # 五段报告结构及各节内容要求
    └── format-guide.md               # 数字编号、证据规范与行文要求
```

## 安装方法

把 `doubao-competitor-report` 整个文件夹放到你的 Skill 根目录下即可，常见位置：

- **豆包工作台（Doubao Work）**：放到工作区 `.skills` 或 `.user_skills` 目录，例如
  `.../workspace/.user_skills/doubao-competitor-report`
- **其他兼容 Claude Skills 格式的 Agent**：放到 `~/.agents/skills` 或对应的 skills 目录

安装后无需额外配置，直接对 AI 说"用竞品报告技能，分析 XX公司（XX赛道）"即可触发。

## 使用方法

- 必填：竞品公司/产品名称
- 可选：赛道/行业（如"CRM""电商SaaS ERP"）、深度档位（默认精简版 8000–12000 字，可指定完整版 15000–30000 字）

示例：「分析纷享销客，CRM 赛道」「用竞品报告技能，拆解有赞，私域电商赛道」

## 报告特性

- 固定五段结构：行业分析 → 定位 → 能力与资源 → 场景与体验 → 总结
- 数字编号标题（1. / 1.1 / 1.1.1）与文档目录，便于快速浏览
- 痛点带概括小标题，解决方案与痛点一一对应
- 竞争态势按"产品介绍 → 优势 → 劣势"铺开，总览表置于文后
- 定位演变用"事件列 + 定位列"两列表格并按阶段总结
- 所有观点要求可靠证据支撑（第三方机构报告、财报、公开访谈等），体验内容注明"基于公开资料"，不编造证据

## 运行依赖

- 本 Skill 在豆包工作台（Doubao Work）环境下可直接运行。
- 文档交付依赖环境的飞书文档能力（lark-doc）与联网检索能力；在其他 Agent 环境使用时可配合各自平台的文档与搜索能力，报告生成逻辑与结构规范完全通用。
